# スコアリング境界ケースメモリ

## 目的

得点、自責点、打点、投手責任、走者状態が壊れやすいケースを継続的に監査する。

## 優先ケース

### エラー絡みの得点

- 出塁がエラーの場合、自責点判定を別途確認する
- その後の進塁が安打、暴投、捕逸、失策のどれによるかを分ける

### 併殺崩れ

- アウトになった走者の責任投手を削除する
- 打者走者が残った場合、槽交替の対象か確認する

### 打席途中投手交代後の四球

- 交代時ボール数が2以上なら旧投手責任
- 交代時ボール数が0または1なら新投手責任
- foulFlyDroppedCountによるストライク選択制約を確認する

### サヨナラ

- 必要な得点が入った時点で試合終了する
- 余分な進塁や得点を記録しない
- 打点、得点、責任投手が期待値と一致する

### タイブレーク

- 初期走者の責任投手、自責点扱いを仕様として明示する
- 保存復元後も初期走者情報を保持する

## 監査メモ

境界ケースは、正しい野球ルールだけでなく、アプリ仕様としてどこまで記録するかも確認する。

記録レベルが低いモードでは、詳細情報を入力しないため、内部で安全な既定値を使う必要がある。
