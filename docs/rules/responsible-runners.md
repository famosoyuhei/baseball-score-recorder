# 責任走者メモリ

## 基本

責任走者は、各走者がどの投手の責任で塁上にいるかを示す。

アプリでは次の3つを並列に管理する。

- `runnersOnBase`
- `runnersEarnedStatus`
- `runnersResponsiblePitcher`

## 管理キー

```js
runnersResponsiblePitcher: {
  first,
  second,
  third
}
```

## 主要ルール

### イニング途中交代なし

全走者は現投手の責任とする。

### 打席途中交代

四球で出塁し、交代時ボール数が2以上なら旧投手の責任とする。

それ以外は新投手の責任とする。

### 槽交替

旧投手の責任走者がアウトになり、同じ打席結果で打者走者が出塁した場合、打者走者が旧投手の責任を引き継ぐ。

### 単純減少

けん制死、盗塁死、走塁死など、打席結果と独立したアウトでは責任走者は単純に減る。

この場合、打者走者への責任引き継ぎは発生しない。

### 優先順位

打席途中交代ルールは槽交替より優先する。

## foulFlyDroppedCount

打席途中交代モーダルのカウント選択制約に使う。

- 1回: ストライク0は選択不可
- 2回: ストライク2に固定
