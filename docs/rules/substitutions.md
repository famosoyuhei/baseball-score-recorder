# 交代メモリ

## 対象

- 投手交代
- 打席途中の投手交代
- 代打
- 代走
- 守備交代

## 投手交代

塁上の走者は、交代前の責任投手を保持する。

交代後の打者走者は原則として新投手の責任とする。

## 打席途中の投手交代

四球で出塁し、交代時ボール数が2以上なら旧投手責任とする。

それ以外は新投手責任とする。

このルールは槽交替より優先する。

## 代走

代走は走者そのものの責任投手と自責点状態を引き継ぐ。

選手IDや表示名が変わっても、責任投手と自責点状態は変えない。

## 代打

代打は打席結果の打者として記録する。

打席途中で代打が出た場合、打席の継承ルールをアプリ仕様として明示する必要がある。

## 守備交代

守備位置や選手名は変わるが、既存走者の責任投手や自責点状態には影響しない。
