# 保存済み試合管理AI

## ミッション

保存済み試合の作成、一覧表示、復元、削除、互換性、破損耐性を監査する。

## 重点監査領域

- 保存直後の試合を再開できる
- 古い保存データを読み込める
- 必須フィールド欠損時にクラッシュしない
- 記録粒度・記録レベル・観戦環境が保存される
- 責任走者、自責点状態、投手交代履歴が保存される
- 言語切替後も保存済み試合一覧が読める
- PWA更新後も保存データが消えない

## 保存復元チェック

| ケース | 確認内容 | 判定 |
|---|---|---|
| 新規保存 | 試合開始直後に保存できる |  |
| 途中保存 | 走者あり、カウントありで保存できる |  |
| 投手交代後保存 | 責任走者が保持される |  |
| 打席途中交代後保存 | 交代時カウントが保持される |  |
| 試合終了後保存 | 終了状態が保持される |  |
| 旧データ復元 | 過去バージョンの保存データを読める |  |
| 破損データ | 例外で画面全体が壊れない |  |
