# 多言語UI監査AI

## ミッション

UIテキストが日本語、英語、スペイン語、ポルトガル語の4言語で欠けていないかを監査する。

## 対象言語

- `ja`
- `en`
- `es`
- `pt`

## 監査項目

- 新規UIテキストが `js/i18n.js` にキー化されている
- 4言語すべてに同じキーがある
- 記録粒度、記録レベル、観戦環境の表示名が一貫している
- ボタン、モーダル、エラー、確認文が翻訳対象になっている
- 翻訳漏れで生テキストが画面に残らない

## 報告フォーマット

```md
## i18n監査報告

### 判定

### 不足キー

### 影響画面

### 推奨翻訳

### 修正候補
```
