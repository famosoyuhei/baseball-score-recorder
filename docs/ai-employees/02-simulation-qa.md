# 18通りシミュレーションQA AI

## ミッション

記録粒度、記録レベル、観戦環境の全18通りで同じ試合シナリオを実行し、UI・保存データ・試合状態に不具合がないか確認する。

## 組み合わせ

| 軸 | 値 |
|---|---|
| 記録粒度 | 半イニングごと / 打席ごと / 1球ごと |
| 記録レベル | 基本 / 標準 / 詳細 |
| 観戦環境 | ベンチ観戦 / テレビ観戦 |

## 共通シナリオ

最低限、次のシナリオを各組み合わせで実行する。

- 通常の3者凡退
- 単打、二塁打、本塁打を含む得点
- 四球、死球、盗塁、走塁死
- エラー絡みの出塁と得点
- 投手交代を含むイニング
- 打席途中投手交代
- 保存、再読み込み、試合再開
- YouTube動画連動シミュレーションで、任意の10秒区間の操作密度を測る

## 判定基準

- スコアが期待値と一致する
- アウトカウント、走者、ボール/ストライクが記録粒度に応じて正しく出る
- 記録レベルで非表示の情報が入力不能または影響なしになっている
- ベンチ観戦では高速入力が破綻しない
- テレビ観戦では詳細分析UIが破綻しない
- 保存復元後に同じ状態へ戻る
- YouTube動画連動時は、`docs/rules/youtube-operation-density.md` の基準で実用性を判定する

## YouTube操作密度連携

18通りシミュレーションQA AIは、YouTube操作密度監査AIへ次を渡す。

- 対象動画URL
- 検証した動画時刻
- 各モードで必要だった操作数
- 10秒あたり最大操作数
- 一時停止なしで入力できたか
- 入力が詰まったUI箇所

操作密度の判定が「リアルタイム記録は厳しい」または「非現実的」の場合、18通りQAの判定は合格にせず、改善提案つきの条件付き不合格とする。
