# PWAインストールガイド

ユーザーに案内するためのPWAインストール手順。公開ページ、SNS投稿、サポート返信、動画台本の元原稿として使う。

## 日本語

### iPhone / iPad Safari

1. SafariでアプリのURLを開く
2. 画面下部の共有ボタンを押す
3. 「ホーム画面に追加」を選ぶ
4. 名前を確認して「追加」を押す
5. ホーム画面のアイコンから起動する

注意: iOSではChromeからホーム画面追加してもPWAとしての挙動がSafariと異なる場合があるため、Safariでの追加を推奨する。

### Android Chrome

1. ChromeでアプリのURLを開く
2. メニューから「アプリをインストール」または「ホーム画面に追加」を選ぶ
3. 追加を確認する
4. ホーム画面またはアプリ一覧から起動する

### PC Chrome / Edge

1. ChromeまたはEdgeでアプリのURLを開く
2. アドレスバー右側のインストールアイコンを押す
3. インストールを確認する
4. デスクトップアプリとして起動する

## English

### iPhone / iPad Safari

1. Open the app URL in Safari
2. Tap the Share button
3. Choose "Add to Home Screen"
4. Confirm the app name and tap "Add"
5. Launch the app from the home screen icon

Note: On iOS, Safari is recommended for installing the PWA.

### Android Chrome

1. Open the app URL in Chrome
2. Tap the menu and choose "Install app" or "Add to Home screen"
3. Confirm the installation
4. Launch the app from the home screen or app drawer

### PC Chrome / Edge

1. Open the app URL in Chrome or Edge
2. Click the install icon near the address bar
3. Confirm the installation
4. Launch the app as a desktop app

## Espanol

### iPhone / iPad Safari

1. Abre la URL de la app en Safari
2. Toca el boton de compartir
3. Elige "Agregar a pantalla de inicio"
4. Confirma el nombre y toca "Agregar"
5. Abre la app desde el icono en la pantalla de inicio

Nota: En iOS se recomienda instalar la PWA desde Safari.

### Android Chrome

1. Abre la URL de la app en Chrome
2. Toca el menu y elige "Instalar app" o "Agregar a pantalla principal"
3. Confirma la instalacion
4. Abre la app desde la pantalla principal o la lista de apps

### PC Chrome / Edge

1. Abre la URL de la app en Chrome o Edge
2. Haz clic en el icono de instalacion junto a la barra de direcciones
3. Confirma la instalacion
4. Abre la app como aplicacion de escritorio

## Portugues

### iPhone / iPad Safari

1. Abra a URL do app no Safari
2. Toque no botao de compartilhar
3. Escolha "Adicionar a Tela de Inicio"
4. Confirme o nome e toque em "Adicionar"
5. Abra o app pelo icone na tela inicial

Observacao: No iOS, recomenda-se instalar o PWA pelo Safari.

### Android Chrome

1. Abra a URL do app no Chrome
2. Toque no menu e escolha "Instalar app" ou "Adicionar a tela inicial"
3. Confirme a instalacao
4. Abra o app pela tela inicial ou pela lista de apps

### PC Chrome / Edge

1. Abra a URL do app no Chrome ou Edge
2. Clique no icone de instalacao perto da barra de enderecos
3. Confirme a instalacao
4. Abra o app como aplicativo de desktop
