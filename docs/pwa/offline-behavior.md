# オフライン動作仕様

球場や遠征先など通信が不安定な環境でも使えるように、PWAのオフライン時の期待動作を明文化する。

## 基本方針

- 試合記録の入力は通信なしでも継続できることを目標にする
- 静的ファイルは Service Worker でキャッシュする
- 保存済み試合は端末内ストレージを前提に扱う
- オフライン時にできない操作がある場合は、ユーザーが理解できる表示にする

## オフラインでできること

- アプリの起動
- 新規試合の開始
- スコア、アウト、走者、投球、打席結果の記録
- 記録レベル `inning` / `batter` / `pitch` の利用
- 記録環境 `bench` / `tv` の利用
- 保存済み試合の読み込み
- 端末内への保存
- 言語切替

## オフラインで制限される可能性があること

- 外部サービスとの連携
- 動画やSNSへの共有
- 別端末との同期
- App Store / Google Play の更新取得
- ブラウザがキャッシュを破棄した後の初回起動

## Service Worker の期待動作

- 初回オンライン表示時に主要ファイルをキャッシュする
- `CACHE_NAME` 変更時に古いキャッシュを削除する
- キャッシュ済みファイルはオフライン時にも返す
- キャッシュに存在しないファイルの失敗が画面全体の停止につながらない

## 保存データの期待動作

- 試合中にページを再読み込みしても直近状態へ戻れる
- 保存済み試合を開いてスコア、走者、投手、責任走者が維持される
- ブラウザのサイトデータ削除時は保存済み試合が消える可能性がある

## QA観点

- [ ] オンラインで一度起動後、オフラインにして再読み込みできる
- [ ] オフラインで新規試合を作成できる
- [ ] オフラインで1イニング分の記録ができる
- [ ] オフラインで保存、再読み込み、復元ができる
- [ ] 通信復帰後も保存済み試合が壊れない
- [ ] `CACHE_NAME` 更新後に古いUIが残らない

## ユーザー向け説明文

このアプリは、一度オンラインで開いた後は通信が不安定な場所でも使えるように設計されています。試合記録は主に端末内に保存されます。端末やブラウザのデータを削除すると、保存済み試合も削除される場合があります。
