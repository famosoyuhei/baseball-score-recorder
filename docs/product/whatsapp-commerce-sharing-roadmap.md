# WhatsApp購入・共有ロードマップ

## 目的

南米日系野球コミュニティ向けに、WhatsAppを中心にした購入、導入、試合結果共有の導線を作る。

このアプリの強みは、PWAとしてURLからすぐ試せること、オフラインで記録できること、試合後にチーム内外へ共有しやすいことにある。販売導線と利用導線をWhatsAppに寄せることで、南米の実運用に合わせる。

## 目指す利用フロー

1. Facebook / Instagram / 紹介でアプリを知る。
2. WhatsApp Businessに問い合わせる。
3. WhatsAppで購入前説明、デモURL、支払い案内を受け取る。
4. PWA URLとホーム画面追加手順を受け取る。
5. 試合前にオンラインで最新版を開き、ホーム画面から起動確認する。
6. 試合中は完全オフラインでも記録する。
7. 試合後にWhatsAppでチーム、保護者、関係者へ結果を共有する。
8. 必要に応じてCSV、JSON、PDF/画像で保存・印刷・分析する。

## 価値仮説

| 仮説 | 内容 |
|---|---|
| 紙のスコアブック代替 | 1試合を安定して記録し、保存、共有、印刷できれば紙の購入理由を減らせる。 |
| WhatsApp共有 | チーム連絡がWhatsApp中心なら、試合結果もWhatsAppで完結する方が自然。 |
| PWA導入 | ストア配布前でもURLとホーム画面追加で小規模チームへ届けやすい。 |
| 南米日系人向け | 現地語、日系野球文脈、WhatsApp相談を組み合わせると大型北米アプリと違う立ち位置を作れる。 |

## 優先実装

| 優先 | 機能 | 目的 | 判定 |
|---|---|---|---|
| 1 | WhatsApp共有用TXT生成 | 試合結果をすぐチームへ送る。 | 最初に作る。 |
| 2 | Web Share API共有ボタン | WhatsAppを含む端末の共有メニューへ渡す。 | TXT生成と同時に検討。 |
| 3 | CSVエクスポート | Excel / Google Sheets / Notionで保存・分析する。 | 通し検証後。 |
| 4 | JSONバックアップ/復元 | 端末紛失、ブラウザデータ削除、別端末移行に備える。 | CSVより優先度を上げる可能性あり。 |
| 5 | PDF/画像出力 | 印刷、保護者共有、提出、SNS共有に使う。 | 共有TXTが刺さった後。 |
| 6 | 印刷用スコアブック表示 | 紙スコアブックの置き換えを強める。 | 実戦ニーズ確認後。 |

## 最小共有テキスト仕様

最初の実装では、プレー詳細よりも試合後共有を優先する。

```text
⚾ 試合結果

{awayTeam} {awayScore} - {homeScore} {homeTeam}

1 2 3 4 5 6 7 | R
{awayShort} {awayInningRuns} | {awayScore}
{homeShort} {homeInningRuns} | {homeScore}

記録: Baseball Score Recorder
{appUrl}
```

絵文字が不要な媒体や環境では、絵文字なし版も用意する。

```text
試合結果

{awayTeam} {awayScore} - {homeScore} {homeTeam}

1 2 3 4 5 6 7 | R
{awayShort} {awayInningRuns} | {awayScore}
{homeShort} {homeInningRuns} | {homeScore}

記録: Baseball Score Recorder
{appUrl}
```

## 共有ボタンの仕様案

| 項目 | 方針 |
|---|---|
| 表示場所 | 試合詳細、試合終了後、保存済み試合詳細。 |
| ボタン名 | `共有` / `Share` / `Compartir` / `Compartilhar`。 |
| 第一候補 | `navigator.share()` が使える端末ではWeb Share APIを使う。 |
| 代替 | 共有テキストをコピーする。 |
| WhatsApp直リンク | 必要なら `https://wa.me/?text=...` を補助導線にする。 |
| オフライン | 共有テキスト生成はオフラインでできる。外部送信はオンライン復帰後に行う。 |

## CSVエクスポート仕様案

CSVは、人がExcel / Google Sheets / Notionへ取り込めることを優先する。

初期CSV:

- `game-summary.csv`
- `inning-linescore.csv`
- `at-bats.csv`

将来CSV:

- `pitches.csv`
- `players.csv`
- `substitutions.csv`
- `pitching-decisions.csv`

## JSONバックアップ仕様案

JSONは、人が読むためではなく、完全バックアップと復元のために使う。

| 項目 | 方針 |
|---|---|
| 対象 | 試合、イニング、打席、投球、選手、設定。 |
| 用途 | 別端末移行、バックアップ、サポート時の再現。 |
| 注意 | 個人名やチーム名を含むため、共有前に注意書きが必要。 |
| 復元 | インポート時に既存試合と衝突しないID処理が必要。 |

## PDF/画像出力仕様案

PDF/画像は、紙の代替とチーム共有の見栄えを担う。

| 出力 | 用途 |
|---|---|
| 試合結果カードPNG | WhatsApp、Facebook、Instagramで見せる。 |
| 簡易スコアシートPDF | 印刷、保護者共有、提出。 |
| 詳細スコアブックPDF | 紙スコアブック代替。実戦検証後に検討。 |

## WhatsApp購入導線

### 問い合わせ後の返信

```text
お問い合わせありがとうございます。
このアプリは、スマホやタブレットで使える野球スコア記録PWAです。

特徴:
- URLからすぐ試せます
- ホーム画面に追加してアプリのように使えます
- 試合前に読み込めば、オフラインでも記録できます
- 試合後に結果をWhatsAppで共有できます

まずはデモURLを開き、ホーム画面に追加してお試しください。
```

### 購入後の案内

```text
ご購入ありがとうございます。

試合前に以下を確認してください。
1. アプリURLをオンラインで開く
2. ホーム画面に追加する
3. ホーム画面アイコンから一度起動する
4. 新規試合を作って保存する
5. 可能なら機内モードで開けるか確認する

試合結果は、試合後に共有ボタンからWhatsAppへ送れるようにしていきます。
```

## ホーム画面追加の説明を必ずセットにする

PWAはApp Store / Google Playから自動でホーム画面に現れる通常アプリとは違う。そのため、販売・モニター募集・購入後案内では必ずホーム画面追加手順をセットにする。

短い説明:

```text
このアプリはPWAです。
App Store / Google Playから入れる通常アプリではなく、URLを開いてホーム画面に追加して使います。
一度追加すると、通常のアプリのようにホーム画面のアイコンから起動できます。
```

最新版確認の説明:

```text
最新版を使うには、試合前に一度オンラインでアプリを開いてください。
完全オフラインで使う場合は、事前にオンラインで起動確認してください。
```

## 販売前の必須条件

- 1試合通し検証でP0/P1が残っていない。
- 保存/復元が実戦で確認されている。
- ホーム画面追加手順をモニターが理解できる。
- 試合前オンライン起動とオフライン利用の関係を説明できる。
- WhatsApp問い合わせリンクが用意されている。
- 共有テキスト生成、または手動で共有できる試合結果表示がある。

## 次の開発タスク候補

1. 試合結果のTXT共有文を生成する。
2. 保存済み試合詳細に共有ボタンを追加する。
3. Web Share APIが使えない環境向けにコピー機能を追加する。
4. UIテキストを `ja` / `en` / `es` / `pt` に追加する。
5. 変更後は `sw.js` の `CACHE_NAME` を上げる。
6. iPhone Safari、Android Chrome、PC Chromeで共有導線を確認する。
