# ターゲットユーザー定義

PWAとして完成度を上げる際に、誰のための改善かを判断するための基準。

## 主要ターゲット

### 1. ベンチ記録者

- 試合中に素早く入力したい
- 画面を見る時間を短くしたい
- 細かい分析より、得点、アウト、走者を確実に残したい
- 通信が弱い球場でも使いたい

刺さる価値:

- `bench` モード
- 少ないタップ数
- オフライン対応
- 保存復元の安定性

### 2. TV観戦記録者

- テレビや配信を見ながら詳しく記録したい
- 投球、打席、責任走者、自責点などを確認したい
- 後で試合を振り返りたい

刺さる価値:

- `tv` モード
- `pitch` レベル記録
- 詳細なスコアブック
- YouTube連動シミュレーション

### 3. 少年野球・アマチュアチームの監督/コーチ

- チームで共有できる記録を残したい
- 専門の記録員がいなくても使える必要がある
- 選手や保護者に説明しやすい記録が欲しい

刺さる価値:

- 簡単な導入
- 多言語UI
- インストール不要でURL共有できること
- 基本記録から詳細記録まで切り替えられること

### 4. 大会運営者

- 複数試合の記録品質をそろえたい
- 記録係への説明を簡単にしたい
- 端末に依存しすぎない運用にしたい

刺さる価値:

- PWA配布
- オフライン動作
- 手順書とチェックリスト
- 記録レベルの選択

## 地域別の訴求

| 地域 | 主な訴求 | 注意点 |
|---|---|---|
| 米国・カナダ | Fast scorekeeping, offline, coach-friendly | GameChangerとの差別化が必要 |
| メキシコ・中米・カリブ | Espanol, uso rapido, sin instalacion obligatoria | スペイン語の野球用語統一 |
| 南米スペイン語圏 | anotacion, marcador, beisbol amateur | 国ごとの用語差 |
| ブラジル | Portugues, sumula, beisebol/softbol | ポルトガル語訳の自然さ |

## 判断基準

- 試合中の入力速度を落とす改善は慎重に扱う
- 初心者向け説明を増やす場合、試合中画面を重くしない
- 多言語対応は販売機能ではなく基本品質として扱う
- オフライン利用と保存復元はPWAの中核価値として守る
