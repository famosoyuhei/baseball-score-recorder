# 競合SWOT分析

南北アメリカ大陸の野球関係者へ売り出す前提で、既存アプリ・代替手段と比較し、このアプリの勝ち筋を整理する。

## 分析対象

| 対象 | 主な位置づけ |
|---|---|
| GameChanger | 北米の大型 youth sports / scorekeeping / live streaming アプリ |
| iScore Baseball / Softball | 詳細スコア記録・スコアカード出力アプリ |
| TeamSnap | チーム、クラブ、リーグ運営プラットフォーム |
| SportsEngine | クラブ、リーグ、大会、配信、登録管理プラットフォーム |
| 紙のスコアブック | 伝統的な手書き記録 |
| 表計算テンプレート | Excel / Google Sheets などの自作記録 |

## 自アプリの基準ポジション

通信が不安定な現場でも使える、多言語対応の軽量な野球スコア記録PWA。

正面から大型チーム管理アプリと戦うのではなく、以下の領域を狙う。

- 記録係がすぐ使える
- チーム登録やアカウント作成の負担が少ない
- オフラインでも使える
- 英語、スペイン語、ポルトガル語、日本語で使える
- 詳細記録と高速入力を切り替えられる
- 小規模大会、草野球、少年野球、TV観戦記録に合う

## 全体SWOT

| 区分 | 内容 |
|---|---|
| Strengths | PWAでURLからすぐ使える。オフライン対応。4言語対応。`inning` / `batter` / `pitch` の記録粒度を選べる。`bench` / `tv` で記録環境を分けられる。責任走者や自責点など記録精度を重視している。 |
| Weaknesses | ブランド力、ストアレビュー、チーム招待、ファン向けライブ配信、既存ユーザー基盤が弱い。ネイティブアプリとしての通知や共有機能は限定的。翻訳の地域別自然さは実地検証が必要。 |
| Opportunities | 中南米・ブラジル・小規模大会・草野球・学校/地域チームでは、大型アプリより軽くて導入しやすいツールが刺さる可能性がある。PWAなのでURL配布、SNS共有、連盟・大会ごとの導入がしやすい。 |
| Threats | GameChangerの無料コーチ機能、TeamSnap/SportsEngineの運営機能、iScoreの詳細記録実績が強い。App Store / Google Playでは既存アプリのレビュー数と信頼が強い。大型競合が多言語・オフライン・簡易記録へ寄せる可能性もある。 |

## 競合別比較

### GameChanger

| 観点 | 分析 |
|---|---|
| 強み | スコア記録、チーム管理、ライブ配信、ハイライト、ファン向け機能、ブランド、レビュー数、パートナー網が非常に強い。コーチ向け無料訴求も強い。 |
| 弱み | 多機能ゆえに、単純に記録したいだけのユーザーには重く感じられる可能性がある。チーム・アカウント・ファン導線が不要な現場には過剰な場合がある。 |
| 自アプリの勝ち筋 | アカウント作成やチーム運用を前提にしない「すぐ記録」「オフライン」「多言語」「軽量」を前面に出す。GameChanger代替ではなく、記録係向けの簡易・現場特化ツールとして訴求する。 |
| 避ける戦い方 | ライブ配信、ハイライト、ファン課金、巨大コミュニティで正面対抗しない。 |

### iScore Baseball / Softball

| 観点 | 分析 |
|---|---|
| 強み | 詳細な野球記録、スコアカード、豊富な統計、ピッチ位置、スプレーチャートなど記録専用アプリとして強い。 |
| 弱み | 詳細機能が多く、初心者や簡易記録ユーザーには学習コストがある可能性がある。PWAのURL即利用とは導入体験が異なる。 |
| 自アプリの勝ち筋 | `inning` / `batter` / `pitch` で段階的に記録レベルを選べる点を打ち出す。初心者は簡単に、上級者は詳細に、同じアプリで移行できることを強みにする。 |
| 避ける戦い方 | 統計項目数やプロ向け分析量だけで競わない。 |

### TeamSnap

| 観点 | 分析 |
|---|---|
| 強み | スケジュール、連絡、登録、支払い、チーム管理、保護者アプリなど運営全体に強い。 |
| 弱み | スコア記録そのものより、チーム/クラブ運営が主目的。単発試合や小規模大会の記録だけなら過剰になりやすい。 |
| 自アプリの勝ち筋 | 運営管理ではなく「試合中の記録体験」に集中する。TeamSnap利用チームでも、試合記録だけ別ツールとして使える立ち位置を狙う。 |
| 避ける戦い方 | 登録、支払い、チーム連絡網を一気に作り込んでTeamSnapの土俵に乗らない。 |

### SportsEngine

| 観点 | 分析 |
|---|---|
| 強み | クラブ、リーグ、大会、登録、決済、配信、トーナメント管理など、大規模組織向け機能が強い。 |
| 弱み | 導入規模が大きく、個人の記録係や小規模チームには重い。スコア記録だけをすぐ始めたい用途とは距離がある。 |
| 自アプリの勝ち筋 | 小規模大会や地域リーグ向けに、導入不要・URL共有・オフライン対応の「現場記録ツール」として訴求する。 |
| 避ける戦い方 | 大会運営SaaS全体を置き換える方向に広げすぎない。 |

### 紙のスコアブック

| 観点 | 分析 |
|---|---|
| 強み | 電池、通信、端末に依存しない。慣れた記録者には速い。自由度が高い。 |
| 弱み | 集計、保存、共有、検索、複製、翻訳、後からの修正に弱い。初心者には記号や書き方が難しい。 |
| 自アプリの勝ち筋 | 紙の自由度を完全に置き換えるのではなく、初心者でも残せる記録、保存復元、共有準備、多言語説明を打ち出す。 |
| 避ける戦い方 | 伝統的スコアブック文化を否定しない。紙に慣れた人には補助ツールとして提案する。 |

### 表計算テンプレート

| 観点 | 分析 |
|---|---|
| 強み | カスタムしやすい。チーム独自の集計や共有に使いやすい。無料で始めやすい。 |
| 弱み | 試合中のスマホ入力には向きにくい。走者、アウト、責任走者、打席途中交代などの状態管理が壊れやすい。 |
| 自アプリの勝ち筋 | 試合中入力のしやすさ、状態管理、自動保存を訴求する。将来的にはCSV/共有出力で表計算との連携を狙う。 |
| 避ける戦い方 | 表計算の柔軟性をすぐに全部取り込もうとしない。 |

## 機能優先順位への示唆

### 最優先

- オフライン起動と保存復元を安定させる
- 初回利用の摩擦を減らす
- 記録中のタップ数を減らす
- `bench` モードの高速入力を磨く
- `ja` / `en` / `es` / `pt` の翻訳品質を上げる
- インストール手順とデータ保存説明を整える

### 次点

- 試合結果の共有用テキスト/画像出力
- CSV出力
- スコアブック表示の見やすさ改善
- 実機別のPWA検証
- App Store / Google Play向けスクリーンショットと説明文

### 後回し

- ライブ配信
- ファン向けSNS機能
- 保護者・チームチャット
- 決済、登録、会費管理
- 大規模大会運営SaaS化

## 推奨メッセージ

### English

Lightweight offline baseball scorekeeping for coaches, scorekeepers, and small tournaments. Start from a URL, install as a PWA, and record in English, Spanish, Portuguese, or Japanese.

### Espanol

Anotacion ligera de beisbol para entrenadores, anotadores y torneos pequenos. Funciona sin conexion, se puede instalar como PWA y esta disponible en espanol, ingles, portugues y japones.

### Portugues

Marcacao leve de beisebol para tecnicos, anotadores e torneios pequenos. Funciona offline, pode ser instalado como PWA e esta disponivel em portugues, ingles, espanhol e japones.

### 日本語

監督、記録係、小規模大会向けの軽量な野球スコア記録PWA。URLからすぐ使えて、オフラインでも記録でき、多言語に対応。

## 次に検証すべき仮説

- GameChangerが重い/過剰だと感じる記録係はどれくらいいるか
- スペイン語圏・ポルトガル語圏でPWAインストールが自然に受け入れられるか
- オフライン対応は購入/導入理由になるか
- `bench` モードの入力速度は紙や既存アプリより速いか
- 翻訳品質は地域の野球関係者に自然に見えるか
