# Docs 作業ガイド

## 範囲

`docs/` は仕様、ルール、QA、PWA、商品・運用資料の置き場。コード実装を伴わない文書更新では `sw.js` のキャッシュバージョン更新は不要。

## 参照方針

- ルール実装を触る前に、必要な文書だけを読む。
- 責任走者は `docs/rules/responsible-runners.md` を優先。
- 得点・自責点は `docs/rules/earned-runs.md` と `docs/rules/scoring-edge-cases.md` を優先。
- PWA 挙動は `docs/pwa/` を優先。
- AI従業員モードは `docs/ai-employees/` と `scripts/ai-employee-mode-matrix.mjs` を優先。

## 多言語

翻訳方針を変える場合は `docs/i18n/translation-style-guide.md` と `js/i18n.js` の整合を確認する。
