# デバイス検証マトリクス

PWAはOS、ブラウザ、インストール方法によって挙動差が出るため、外部公開前に実機または近い環境で確認する。

## 検証対象

| 優先度 | デバイス | OS | ブラウザ | 確認理由 |
|---|---|---|---|---|
| 高 | iPhone | iOS 最新系 | Safari | iOS PWAの主要導線 |
| 高 | Androidスマホ | Android 最新系 | Chrome | Android PWAの主要導線 |
| 高 | Windows PC | Windows 10/11 | Chrome | 開発・大会運営者の利用想定 |
| 中 | Windows PC | Windows 10/11 | Edge | PWAインストール導線確認 |
| 中 | iPad | iPadOS 最新系 | Safari | ベンチ・記録係の大型画面利用 |
| 中 | Androidタブレット | Android 最新系 | Chrome | 大型画面利用 |
| 低 | macOS | 最新系 | Safari / Chrome | 北米ユーザーの補助確認 |

## 検証項目

- [ ] 初回表示
- [ ] ホーム画面追加またはインストール
- [ ] インストール後の全画面起動
- [ ] オフライン再読み込み
- [ ] 新規試合作成
- [ ] 1イニング分の記録
- [ ] 保存済み試合の復元
- [ ] 言語切替
- [ ] 画面回転
- [ ] 小さい画面でのボタン崩れ
- [ ] Consoleエラー
