# データ保存とプライバシー

このアプリが扱うデータと保存場所を説明する。公開ページ、ストア審査、問い合わせ対応の元情報として使う。

## 基本方針

- 試合記録は主にユーザーの端末内に保存する
- サーバーへ自動送信する設計ではない
- アカウント登録を前提にしない
- 外部共有や同期機能を追加する場合は、この文書を更新する

## 保存される可能性がある情報

- チーム名
- 選手名
- 試合日時
- 得点
- 打席結果
- 投球結果
- 走者状況
- 投手交代情報
- 責任走者情報
- 保存済み試合データ
- 言語設定などの表示設定

## 保存場所

| 種類 | 保存場所 | 備考 |
|---|---|---|
| 試合データ | ブラウザのローカルストレージまたはIndexedDB相当 | 端末・ブラウザに依存 |
| PWAキャッシュ | ブラウザのCache Storage | Service Workerが管理 |
| 設定 | ブラウザ内ストレージ | 言語など |

## ユーザーが知るべきこと

- 同じ端末・同じブラウザで保存済み試合を開ける
- 別端末への自動同期は前提にしない
- ブラウザのサイトデータを削除すると、保存済み試合が消える可能性がある
- 端末の紛失や共有端末利用時は、保存済みデータが他者に見られる可能性がある

## 外部送信

現時点では、試合データをアプリ側のサーバーへ自動送信する前提ではない。将来、共有、クラウド同期、チーム管理、分析送信などを追加する場合は、送信先、目的、保存期間、削除方法を明記する。

## 公開用の短い説明文

このアプリの試合記録は、基本的にお使いの端末内に保存されます。アカウント登録やサーバー送信を前提としないため、ブラウザのサイトデータを削除すると保存済み試合も削除される場合があります。
