# 既知の制約と回避策

外部ユーザーへ案内するための既知の制約、不具合、回避策を管理する。公開前は空にせず、PWA固有の注意点を明記しておく。

## PWA / インストール

| 状態 | 内容 | 回避策 | 更新日 |
|---|---|---|---|
| 既知 | iOSではPWAのインストールはSafariから行う必要がある | iPhone/iPadではSafariで開き、共有メニューからホーム画面に追加する |  |
| 既知 | ブラウザのサイトデータを削除すると保存済み試合も消える可能性がある | 重要な試合は削除前に必要な情報を控える |  |
| 既知 | 初回利用時はオンライン接続が必要 | 一度オンラインで開いてからオフライン利用する |  |

## オフライン

| 状態 | 内容 | 回避策 | 更新日 |
|---|---|---|---|
| 既知 | キャッシュ前のファイルはオフラインで開けない | 試合前にオンライン状態で一度起動する |  |
| 既知 | ブラウザが容量節約のためキャッシュを削除する場合がある | 大事な試合前に起動確認する |  |
