# CSS 作業ガイド

## キャッシュ

CSS を変更したら、必ず `../sw.js` の `CACHE_NAME` を 1 つ上げる。

## 記録レベル別の表示制御

`#gameScreen` には `game.recordingLevel` に応じたクラスが付与される。

| クラス | 意味 | 表示するもの |
|---|---|---|
| `inning-level` | 半イニングごと | スコアボードのみ |
| `batter-level` | 打者ごと | アウトカウント・走者状況まで |
| `pitch-level` | 球ごと | ボール/ストライクカウントまで |

この粒度制御に関わる変更は、`style.css` の「記録レベル別の表示制御」セクションを優先して確認する。

## 禁止事項

投手・打者の左右（利き手）表示は追加しない。
