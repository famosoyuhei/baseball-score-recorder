# JavaScript 作業ガイド

## キャッシュ

JS を変更したら、必ず `../sw.js` の `CACHE_NAME` を 1 つ上げる。

## 記録レベル（recordingLevel）

試合開始時に選択される記録の粒度。`game.recordingLevel` に格納され、`#gameScreen` の CSS クラスとして付与される（例: `inning-level`）。

| 値 | 表示名 | UIに表示するもの |
|---|---|---|
| `inning` | 半イニングごと | スコアボードのみ |
| `batter` | 打者ごと | + アウトカウント・走者状況 |
| `pitch` | 球ごと | + ボール/ストライクカウント |

CSS での表示制御は `../css/style.css` の「記録レベル別の表示制御」セクションで行う。

## 記録環境（recordingMode）

| 値 | 表示名 | 用途 |
|---|---|---|
| `bench` | ベンチ記録 | 簡素化された高速入力UI |
| `tv` | TV観戦記録 | 詳細分析機能つき |

## 責任走者（Responsible Runner）追跡

各走者がどの投手の責任走者かを `runnersResponsiblePitcher: { first, second, third }` で管理する。`runnersOnBase` / `runnersEarnedStatus` と並列に保持する。

主要ルール:

- イニング途中交代なし: 全走者が現投手の責任。
- 打席途中交代: 四球かつ交代時ボール数が 2 以上なら旧投手の責任。それ以外は新投手の責任。
- 槽交替（Slot Substitution）: 旧投手の責任走者がアウトになり打者走者が出塁した場合、打者走者が旧投手の責任を引き継ぐ。
- 単純減少: けん制死・走塁死など打席結果と無関係のアウトは責任走者が単純に減る（槽交替なし）。
- 打席途中交代ルールは槽交替より優先。

`foulFlyDroppedCount` は打席途中交代モーダルのカウント選択制約に使用する（AtBat 単位で管理）。

- 1回: ストライク 0 は選択不可。
- 2回: ストライク 2 に固定。

## 多言語対応

UI に新しいテキストを追加する場合は、`i18n.js` で `ja` / `en` / `es` / `pt` の 4 言語すべてにキーを追加する。
